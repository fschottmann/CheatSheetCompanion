# Meeting Notes

This note has `csc: ignore` in its front matter: it is never shown automatically, even if a window title happens to contain "Meeting Notes". It still appears in the search (Ctrl+K).

Use this for notes that would produce random matches: daily notes, meeting minutes, journals. Whole folders can be excluded with `MatchIgnoreFolders` (the `Daily` folder in this demo).
