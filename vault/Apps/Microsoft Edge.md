# Microsoft Edge

One note for all browsers: the aliases *Edge*, *Chrome*, *Brave* and *Firefox* appear in their window titles and process names.

## Shortcuts

| Keys | Action |
| --- | --- |
| Ctrl+L | Address bar |
| Ctrl+Shift+T | Reopen closed tab |
| Ctrl+Shift+N | InPrivate window |
| F12 | Developer tools |
| Ctrl+Shift+Delete | Clear browsing data |
| Ctrl+J | Downloads |

## Address bar tricks

- `edge://flags`, `edge://settings/reset`, `chrome://net-internals`
- Search a site directly: `site:learn.microsoft.com webview2`
