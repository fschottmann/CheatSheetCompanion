# Microsoft Teams

## Shortcuts

| Keys | Action |
| --- | --- |
| Ctrl+E | Search |
| Ctrl+N | New chat |
| Ctrl+Shift+M | Mute / unmute |
| Ctrl+Shift+O | Camera |
| Ctrl+Shift+K | Raise hand |
| Shift+Enter | New line in a message |

## Formatting a message

- Code block: type three backticks, or paste from the companion with *Copy as… formatted* (right-click) so lists and code arrive formatted. Plain text goes in with *Copy to clipboard*.
- Quote: `>` at the start of a line.
- Mention a channel: `@Channel name`.
