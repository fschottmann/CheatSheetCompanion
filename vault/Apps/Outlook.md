# Outlook

## Shortcuts

| Keys | Action |
| --- | --- |
| Ctrl+N | New mail |
| Ctrl+R / Ctrl+Shift+R | Reply / reply all |
| Ctrl+Shift+V | Move to folder |
| Ctrl+Shift+G | Flag for follow-up |
| Ctrl+E | Search |
| Alt+S | Send |

## Search syntax

- `from:Smith received:this week`
- `hasattachment:yes subject:invoice`
- `category:"Project X"`

Pasting a note with *Copy as… formatted* keeps headings and tables in the mail body.
