# Windows Explorer

The Explorer window title is the folder name, so this note is matched through the process name `explorer`.

## Shortcuts

| Keys | Action |
| --- | --- |
| Alt+D | Address bar (type `cmd` or `pwsh` to open a shell here) |
| Ctrl+Shift+N | New folder |
| Alt+Enter | Properties |
| F2 | Rename (Tab renames the next file) |
| Shift+Right-click | *Copy as path*, *Open PowerShell window here* |
| Alt+P | Preview pane |

## Paths worth knowing

- `shell:startup` autostart folder
- `%LocalAppData%\CheatSheetCompanion` state, log and WebView2 profile of the companion
